Suppression des données

Momenta · com.axelchabe.momenta · Dernière mise à jour : 15 octobre 2026

Cette page explique comment effacer les données associées à Momenta, que l’application soit encore installée ou non. Consultez aussi la Politique de confidentialité.

1. Effacer toutes les données de Momenta

  1. Ouvrez les Paramètres de votre appareil Android.
  2. Ouvrez Applications, puis sélectionnez Momenta.
  3. Ouvrez Stockage et cache (le nom peut varier selon l’appareil).
  4. Sélectionnez Effacer le stockage ou Effacer les données, puis confirmez.

Cette action efface les données locales de Momenta sur l’appareil, notamment les notes, tags, l’historique, la progression de session et les préférences de rappel. Elle ne peut pas être annulée.

Vous pouvez aussi désinstaller Momenta pour supprimer ses données locales. Selon vos réglages Android, une sauvegarde gérée par le système peut conserver certaines données et éventuellement les restaurer ultérieurement.

2. Ce qui n’est pas supprimé

  • Vos photos originales : elles restent dans la photothèque de votre appareil. Momenta ne les copie pas dans son propre stockage ; effacer les données de l’application ou la désinstaller ne supprime donc pas ces photos.
  • Les données de l’application choisie pour partager une photo : si vous avez partagé une photo, toute copie enregistrée par l’application destinataire relève de cette application. Vous devrez la supprimer auprès de son fournisseur.
  • Les éventuelles sauvegardes Android : leur suppression et leur durée de conservation dépendent des réglages et services de sauvegarde de votre appareil et de votre compte.

3. Demande par e-mail

Momenta ne crée pas de compte et ne conserve pas de données personnelles sur un serveur du développeur. Les données de notes, tags et historique sont stockées localement sur votre appareil ; nous ne pouvons pas les consulter ni les effacer à distance. Pour toute question, vous pouvez écrire à axelchabe.dev@gmail.com. N’incluez pas de photo ni d’information sensible dans votre message.
